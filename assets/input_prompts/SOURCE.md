# Kenney Input Prompts

- Author: Kenney
- Source: https://kenney.nl/assets/input-prompts
- Package version: 1.5A (as recorded in the included original `License.txt`)
- License: Creative Commons Zero (CC0)

This subset contains keyboard, Xbox and PlayStation SVG prompts used by the input help UI. The original vector paths are retained. The root viewport and intrinsic dimensions were cropped to the glyph bounds, with one source unit of transparent padding, so different key shapes remain centered and legible at UI sizes. Empty `defs` nodes were removed for Flutter SVG compatibility.

`manifest.json` records the downloaded archive hash, original package paths, original SVG hashes, and resulting file hashes. The original license is preserved alongside the assets.
