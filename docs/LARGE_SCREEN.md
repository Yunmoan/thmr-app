# 大屏模式

适用于 THO、展位和其他线下活动。桌面端 Windows、macOS、Linux 可用，与普通界面共用频道、音频和播放状态。

## 入口与窗口

收听页「复制信息」右侧的显示器图标打开大屏模式，F11 也可打开。使用外接屏幕时，先将窗口移到目标屏幕。

- 左上角固定显示「东方音乐电台 / Touhou Music Radio」。
- 右上角的四角符号切换系统全屏，向下符号收起大屏、返回普通界面。按钮都有悬浮说明和读屏名称。
- 窗口化时可拖动左上角标题与留白移动窗口。频道选择器直接切换当前放送频道，切换期间保留画面并显示状态提示。
- 大屏内按 F11 切换全屏；退出全屏后可以继续使用窗口化大屏。Esc 或手柄 B / ○ 收起大屏。
- 收起后保留页面、滚动位置、键盘焦点和播放状态，并恢复进入前的窗口全屏状态。
- Windows 迷你播放器与大屏互斥，快捷键切换时先退出当前模式。切换主页面、搜索或打开操作帮助时会先收起大屏。

## 个性化

在「我的 → 外观 → 大屏模式」设置，选择立即保存，重启后继续使用。「恢复默认」仅恢复大屏设置。

| 选项 | 内容 |
| --- | --- |
| 布局 | 自动、封面在左、封面在右、上下居中；SVG 小图展示对应布局 |
| 画面范围 | 铺满窗口，或居中适应；居中适应将内容限制在 1560 × 1000 逻辑像素以内 |
| 封面显示 | 完整显示原图，或按封面区域裁切铺满 |
| 播放队列 | 隐藏、只显示下一首、横向排列、列表；列表使用完整队列、填满列表区域并可滚动，宽屏在右侧、窄屏移至下方 |
| 横向队列曲目数 | 横排显示 3、5、8 首；不限制列表式队列 |
| 队列封面 | 显示或隐藏队列缩略图 |
| 曲目信息字号 | 调整曲名与作者字号 |
| 大屏主题 | 跟随应用、独立浅色、独立深色；保留当前角色的强调色 |
| 背景立绘 | 显示当前主题的角色背景 |
| 立绘位置 | 右下角（默认）或左下角 |
| 卡片式布局 | 可选纸面板背景，默认关闭，播放区直接使用页面背景 |
| 直播进度 | 显示或隐藏电台放送进度 |
| 播放控制栏 | 显示或隐藏底部播放、静音与音量控件 |
| 自动收起控制栏 | 闲置 4 秒后隐藏控制栏和光标，鼠标、键盘或手柄操作时恢复；右上角窗口按钮始终保留 |
| 打开时进入全屏 | 自动全屏，或在当前窗口内打开大屏界面 |

默认跟随应用明暗主题，沿用思源宋体、角色立绘和主题色。默认采用无卡片的布局，需要时可开启与普通界面相同的纸面板。封面加载期间或请求失败时显示品牌占位图。极矮的窗口会等比缩小内容，避免切掉退出按钮。

大屏进出、布局、曲目信息、页面与状态提示使用统一的过渡规范，并响应系统“减少动画”设置。状态提示保留退出动画，操作或新提示可打断旧动画。

## 播放与状态

进入、全屏切换、收起均不新建或重连音频。沿用 Ctrl（macOS 为 ⌘）+ P 播放 / 暂停、Ctrl / ⌘ + 上下方向键调节音量，以及既有手柄操作。直播进度反映电台放送时间，本机暂停时电台仍继续放送。

连接、缓冲、播放错误和信息获取失败会显示对应状态。大屏期间隐藏应用更新横幅，返回后可继续查看。

## 验证

`test/large_screen_test.dart` 覆盖布局与队列组合、七种尺寸、系统文字放大、窗口切换、焦点和页面保留、失败恢复、显示前的绘制屏障。`test/large_screen_settings_test.dart` 覆盖配置存取、异常值、连续修改和设置页面。

Windows 原生切换检查：关闭正在运行的 THMR 后运行 `flutter run -d windows -t tool/large_screen_smoke.dart --no-pub`。该检查使用真实窗口和绘制屏障，不播放音频、不访问网络、不写入偏好设置。
