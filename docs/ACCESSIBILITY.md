# 键盘、手柄与无障碍

本文范围为 Flutter 客户端。键盘、手柄共用应用命令，手柄通过 `gamepads` 的标准化事件接入 Windows、macOS、Linux、Android 和 iOS 原生实现。平台插件声明支持不等于本项目已完成各平台实物设备验收。

## 操作

按 F1，或在「我的」页面下方的「操作帮助」分区打开图文按键说明。键盘与手柄分别显示；左栏居中展示组合键图标，右栏为左对齐的文字说明。Kenney Input Prompts 图标的来源、CC0 许可证及文件哈希保存在 `assets/input_prompts/`。

在 macOS 上，下表的 Ctrl 使用 ⌘。

| 键盘 | 操作 |
| --- | --- |
| Tab / Shift+Tab | 下一个 / 上一个控件 |
| 方向键 | 按控件默认方式移动焦点或操作 |
| Enter / 空格 | 激活选中的按钮 |
| Ctrl+1 / 2 / 3 / 4 | 收听 / 曲库 / 收藏 / 我的 |
| Ctrl+F | 切到曲库并聚焦搜索框 |
| Ctrl+P | 播放 / 暂停 |
| Ctrl+M（macOS：⌘+Shift+M） | 静音 / 恢复之前的非零音量；保留 ⌘+M 最小化 |
| Ctrl+↑ / ↓ | 音量增加 / 减少 5% |
| Ctrl+Shift+M | 切换迷你播放器，仅 Windows |
| Esc | 关闭可取消的弹窗、返回；迷你模式下恢复主窗口 |
| F1 | 操作说明 |

音量滑杆可用四个方向键调整，Home / End 设置为 0% / 100%。普通空格和文本编辑键保留控件自身行为；不占用 Ctrl+空格这一常见输入法组合。

| 手柄位置（Xbox / PlayStation） | 操作 |
| --- | --- |
| 十字键 / 左摇杆 | 按方向移动焦点 |
| A / × | 激活选中的控件 |
| B / ○、Back / Share | 关闭可取消的弹窗或返回 |
| X / □ | 播放 / 暂停 |
| Y / △ | 曲库搜索 |
| LB / L1、RB / R1 | 上一个 / 下一个主页面 |
| 右摇杆上下 | 滚动焦点所在的可滚动区域 |
| 右摇杆按下 | 静音 / 恢复音量 |
| Menu / Options | 操作说明 |

手柄操作音量滑杆时，左右调整音量，上下离开滑杆。左摇杆启动阈值为 0.55，回中阈值为 0.35；方向和滚动按住 400 ms 后每 110 ms 重复。确认、返回、媒体按钮不重复执行。断连和窗口失焦会清理按住状态，后台窗口不响应手柄。

弹窗打开时，切页和搜索不会改变背后的页面。必须通过按钮完成的不可取消弹窗不会被 Esc 或 B 绕过。迷你播放器有键盘焦点或启用系统无障碍导航时保持展开。

## 已覆盖的无障碍行为

- 隐藏标签页和迷你模式下保留的主窗口退出焦点遍历；窗口切换过程中禁止对界面操作。
- 切换主页面后焦点进入对应页面，页面边界允许返回侧栏或底栏。
- 自绘音量滑杆和主要自绘按钮有可见焦点提示，按钮焦点使用黑白双描边以适应不同底色。
- 窗口、播放、静音按钮有操作名称；自定义底栏暴露选中状态；音量暴露数值与增减动作。
- 10 个角色的明暗主题分别检查强调文字对实色面板、按钮文字对实色强调背景的 4.5:1 对比度。背景插画和透明面板的每一种合成结果仍需视觉检查，不能由令牌测试替代。
- 减弱动画设置会停用页面、背景、迷你窗口相关过渡和播放频谱运动；迷你副标题停止自动轮换。底栏高度随文字大小增长。
- 迷你播放器三个尺寸均覆盖 100%、130%、200% 文字缩放；音量百分比预留实际文字宽度，副标题高度随文字增长。

## 验证与边界

`test/accessibility_test.dart` 验证隐藏焦点、语义名称、音量键盘行为和主题对比度；`test/gamepad_navigation_test.dart` 验证死区、重复、断连和命令转换；`test/app_input_test.dart` 验证真实 Flutter 控件上的快捷键、手柄焦点、弹窗和前后台状态。

手柄支持的是界面导航与播放器控制；未内置桌面手柄软键盘，登录、搜索词、昵称和反馈文字仍需要键盘或系统输入法。登录 WebView 内的交互由网页及平台 WebView 决定。

发版前还需使用 Windows NVDA / 讲述人、macOS / iOS VoiceOver、Android TalkBack 检查完整收听、搜索、收藏、登录和反馈流程，并用真实手柄确认有线、蓝牙、断连、重新连接及后台窗口行为。没有完成这些验收前，不应宣称全应用符合 WCAG AA 或所有流程均可纯手柄完成。
