# 键盘、手柄与无障碍

[返回使用指南](README.md)

在桌面端按 F1，或到「我的 → 操作帮助 → 键盘与手柄操作」查看图文按键。客户端前台可用手柄导航，文本输入使用键盘或系统输入法。登录 WebView 内的交互由页面和平台 WebView 处理。 [按键素材来源与许可证](../../assets/input_prompts/SOURCE.md)

## 键盘

在 macOS 上可用 ⌘ 替换下表的 Ctrl，静音与迷你播放器使用表中注明的例外。

| 按键 | 操作 |
| --- | --- |
| Tab / Shift+Tab | 下一个 / 上一个控件 |
| 方向键 | 按控件规则移动焦点或调整设置 |
| Enter / 空格 | 激活选中的按钮 |
| Ctrl+1 / 2 / 3 / 4 | 收听 / 曲库 / 收藏 / 我的 |
| Ctrl+F | 切到曲库并聚焦搜索框 |
| Ctrl+P | 播放 / 暂停 |
| Ctrl+M / ⌘+Shift+M | 静音 / 恢复音量。macOS 的 ⌘+M 仍用于最小化。 |
| Ctrl+↑ / ↓ | 音量增加 / 减少 5% |
| Ctrl+Shift+M | 切换 Windows 迷你播放器 |
| Esc | 关闭可取消的弹窗或返回，也可恢复迷你播放器的主窗口 |
| F11 | 打开桌面大屏幕模式或切换全屏 |
| F1 | 打开操作说明 |

音量滑杆有焦点时可用方向键调整，Home / End 分别设为 0% / 100%。

## 手柄

| 按键（Xbox / PlayStation） | 操作 |
| --- | --- |
| 十字键 / 左摇杆 | 按方向移动焦点 |
| A / × | 激活选中的控件 |
| B / ○、Back / Share | 关闭可取消的弹窗或返回 |
| X / □ | 播放 / 暂停 |
| Y / △ | 曲库搜索 |
| LB / L1、RB / R1 | 上一个 / 下一个主页面 |
| 右摇杆上下 | 滚动焦点所在的区域 |
| 右摇杆按下 | 静音 / 恢复音量 |
| Menu / Options | 打开操作说明 |

在音量滑杆上，左右调整音量，上下离开滑杆。方向和滚动按住后可重复，确认、返回和媒体操作只响应一次按压。断连或窗口失焦会清除按住状态。

## 焦点、读屏和动画

隐藏页面退出焦点遍历，自绘按钮和滑杆显示焦点提示。播放和窗口按钮提供读屏名称，导航项报告选中状态，音量提供当前值及增减动作。底栏和迷你播放器适应系统文字大小。系统启用「减少动画」时，页面、背景、窗口切换和频谱会减少运动。迷你播放器有键盘焦点或系统启用无障碍导航时保持展开。 [无障碍验证](../development/verification.md)
