# 播放源与网络诊断

[返回使用指南](README.md)

## 切换播放源

在「我的 → 播放与网络」选择「自动测速」「源 1」或「源 2」。选择会保留到下次启动。自动模式对两路直播流各读取最多 32 KiB 音频，比较实际取得音频的耗时。有可用的来源且改善达到切换阈值时会切换，也可在设置中手动重新测速。

切换来源时保留码率。播放中会重新连接，暂停时保持暂停。手动指定的来源由用户决定。

## 导出诊断报告

打开「我的 → 播放与网络 → 网络诊断」查看公网 IP 与属地、本机 IPv4/IPv6 接口、系统环境和内存，以及各服务的 HTTP 状态、响应耗时、DNS、实际连接 IP 和 CDN 响应标识。收到 HTTP 响应即表示连接可达，例如根路径返回 404。定位服务异常时也要参考具体状态码。

「导出 TXT」使用系统另存为窗口，生成 UTF-8 BOM 文本。报告包含网络和系统信息，登录凭据、Cookie 与媒体访问密钥会排除。开发者可通过 [手动检查](../development/verification.md#手动检查) 运行同一套诊断。
