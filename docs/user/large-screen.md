# 大屏幕模式

[返回使用指南](README.md)

大屏幕模式在 Windows、macOS、Linux、Android 和 iOS 上可用，与普通界面共用频道、音频和播放状态。

## 打开和退出

- 点击收听页「复制信息」旁的显示器图标。桌面也可按 F11。使用外接屏幕时，先把主窗口移到目标屏幕。
- 桌面右上角的四角图标切换系统全屏，窗口化时可拖动顶部标题和留白。F11 在大屏幕内切换全屏。
- 手机上的界面随系统横竖屏变化，竖屏上下排布。iPad 在分屏时沿用平板布局。移动端可在设置里启用屏幕常亮。
- 点击收起按钮返回普通界面，或按 Esc、手柄 B / ○。原页面、焦点和播放状态会保留。Windows 的迷你播放器与大屏幕模式互斥。 [键盘与手柄操作](accessibility.md)

## 设置和预览

在「我的 → 外观 → 大屏幕模式 Beta 配置」调整画面，选择会自动保存。可从设置页预览显示效果。

| 设置 | 用途 |
| --- | --- |
| 布局与画面范围 | 自适应、封面居左、封面居右或上下布局，可限制显示区域并调整边距。 |
| 封面与播放队列 | 完整显示或裁切封面。队列可隐藏、仅显示下一首、横排或使用可滚动列表。 |
| 曲目信息与外观 | 调整信息字号、独立的明暗主题、卡片背景、角色立绘位置和透明度。 |
| 音乐动效 | 选择极光流场、星云漫游、棱镜涟漪、镜像频谱、流体渐变或关闭，按需调整强度和省电模式。 |
| 小组件 | 添加时钟、日期和文本，分别设置位置、格式与外观。 |
| 播放控制 | 选用直播进度与底部控制栏。启用自动收起时，操作鼠标、键盘或手柄可唤回控制栏。 |

切换全屏和退出大屏幕会沿用现有播放连接。直播进度表示电台放送时间，本机暂停时电台仍继续放送。

开发者的窗口验证命令见 [手动检查](../development/verification.md#手动检查)。
